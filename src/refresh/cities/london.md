Refresh "London Weekend Fetch" (theweekendfetch.com/london/), the London, UK edition of a live events site (repo oalwyn/weekly-fetch). Readers are households across London, some with dogs, planning weekends with friends. The aim is to get people out of the house AND bring communities together, so speak to everyone: families, teens, young adults, older people, newcomers and London's many cultures. Use London dates and times (GMT until Mar 28, 2027, then BST) and British spelling. This refresh runs once a week (Monday morning), so the list must hold up for the whole week ahead.

This is a thorough research job: expect 80+ searches and page fetches. Don't stop or push to main until the counts in step 6 are met or you have genuinely exhausted sources for a category (say which in your final message). If a page fails, retry once with `curl -sL -A "Mozilla/5.0"`, then use WebSearch. WebSearch is limited to about 200 calls per run, so prefer reading official pages directly.

SAVE AS YOU GO (most important rule). Earlier runs were cut off by usage limits part-way and lost everything. So work in groups and save each finished group to the branch `london-wip`, so a later run can carry on instead of starting over.
   Groups, in this order: A farmers markets and other markets (mkt); B Christmas & winter (hol); C concerts, theatre, panto, comedy (show); D sport; E new films (film); F kids, teen and programs (kids, teen, prog); G art, food, dog, evt; H community join + vol; I community cult + learn + fmd; J local independent businesses (local/biz); K final balance pass (regions, free share, aud, every week has 20+ things).
   After EACH group: make london/data.js valid (step 8 check passes), update london/PROGRESS.md (date of this run, each group done/not done with its item count, and a short list of sources already checked), then `git add london/data.js london/PROGRESS.md && git -c user.name=Claude -c user.email=noreply@anthropic.com commit -m "London refresh in progress: group <X>" && git push -u origin london-wip`. Never go more than about 25 new items without saving. Inside a group you may also save mid-way.
