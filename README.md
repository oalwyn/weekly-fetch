# The Bay Area Weekend Fetch

Bay Area weekend events: holiday markets, concerts, kids & teen picks, dog walks, pizza and coffee, from Napa/Sonoma and Marin down to Carmel. Live at https://oalwyn.github.io/weekly-fetch/

- `index.html`: the app (built from `src/` with `python3 src/build.py`, don't hand-edit)
- `src/`: app source, build script and tests (see CLAUDE.md)
- `data.js`: event list (refreshed automatically every Monday and Thursday)
- `walks.js`: dog walks (edited by hand)
